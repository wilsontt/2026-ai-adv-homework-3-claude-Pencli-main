### 2. 透過 Playwright 進行E2E 測試：
1. 先確認啟動 npm run dev:server，以具備存取外部網路的權限。
2. 開啟 3001 port 進入網頁，如果沒有開啟伺服器，請自行開啟。
3. 登入帳號及密碼，在 .env 內。
4. 加入一個品項到購物車。
5. 進行結帳。
6. 在結帳過程中會進入到綠界金流。
   1. 請選擇 信用卡付款。
   2. 填入測試卡號欄位（id: CCpart1~CCpart4）：4311 9522 2222 2222
   3. 填入有效期（id: creditMM / creditYY）：12 / 26
   4. 填入安全碼（id: CreditBackThree）：222
   5. 點擊右側橘色「測試付款請點此」（id: aCREDIT）
   6. 此連結會在新分頁開啟 MockScanCodePay 模擬付款頁
   7. 切換至新分頁，確認卡號 4311952222222222 已帶入
   8. 點擊「交易成功」按鈕（input[value="交易成功"]）
   9. 新分頁關閉後記錄 tradeNo（從 ECPay 頁面訂單資訊取得）
7. 完成後，再將測試結果寫一份測試報告，文件以MD檔儲存。
